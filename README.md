 Unofficial Manifest V3 port of MyJDownloader Browser Extension 3.3.20 for the latest Chrome.

 Install

  1. Download and extract the zip.
  2. Open chrome://extensions and enable Developer mode.
  3. Remove the original MyJDownloader extension if installed.
  4. Click "Load unpacked" and select the extracted myjdownloader-extension-3.4.0 folder (the one containing
  manifest.json).
  5. Keep the folder in place. Chrome loads the extension from it, so deleting or moving it breaks the extension.
